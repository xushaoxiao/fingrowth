# Changelog

## 0.1.0 — 2026-11-03

- Five consumer-lending Agent Skills (including a source adapter) for growth architecture, metric trees, funnel diagnosis and experiment design, each with standalone supporting resources.
- A dependency-free synthetic cohort calculator producing JSON and Markdown, with strict validation, explicit denominators and separate investigation rankings by count and conversion.
- Synthetic lending case and walkthrough showing lower funded CAC alongside worse contribution, without claiming channel causation.
- Isolated Agent task acceptance records with source tasks, actual deliverables and independent review; see `evals/` for outcomes and limitations.
- Corrected decimal precision when summing very large accepted costs before cancellation, with large-value and fractional-cost regression tests.
- Next.js + HeroUI static dashboard with six growth views, local import/export, provenance, exact-cent contribution and eight selectable palettes.
- Strict duplicate-key, timestamp and UTF-8 workspace-capacity validation across mapper/browser, with atomic invalid-import behavior.
- Standalone static dashboard ZIP includes the project license and retained dependency notices.
- Reproducible licensed ZIPs for the source and five skills, plus an optional static dashboard, a source-commit manifest and SHA-256 checksums; dirty checkouts and artifact overwrites are rejected.

This version does not verify real lending performance, legal compliance, automatic host discovery or compatibility with every agent. Maturity remains supplied metadata. No production integrations or experiment power calculator are included.
