# Design decisions

2026-11-02 — Python standard library keeps the demo reproducible without credentials or network access. Aggregate synthetic fixtures prevent accidental use of real customer records. Deterministic arithmetic is separated from agent judgment. MIT enables reuse; host compatibility and legal suitability remain separately evaluated. No employer experience is asserted as a verified case study: current inputs support general architecture only. GitHub browser and connector authentication restored for initial public publication. Feishu synchronization remains pending an authorized writable connection.

2026-11-03 — Usability iteration keeps the existing fixture array and JSON fields, adding diagnostics and Markdown output. A single calculator implementation lives inside the funnel skill so copying that folder preserves execution; the root command is a compatibility wrapper. Strict field/date/maturity validation intentionally rejects previously tolerated malformed fixtures. Investigation rankings distinguish count gaps from conversion rates and exclude repayment/repeat from onboarding priorities. Maturity remains declared metadata, not a verified outcome. Each skill now carries only its task-specific supporting resource. File-copy execution is tested separately from agent-host discovery. No release tag, production integration or external knowledge-base sync is implied.
