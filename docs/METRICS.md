# Metric contract

Fixture unit: one synthetic acquisition cohort, USD, January 2026, outcomes observed October 31. Counts are nested unique people with at most one first loan, and repaid means full contractual repayment within this example's observation horizon. Repeat is a subset of fully repaid people. This simplified model excludes overlapping repeat-loan exposures. Real event streams require deduplication, join keys and loan-level exposure accounting before aggregation.

Step conversion = next / previous; funded CAC = acquisition cost / disbursed. Zero denominator → null. Contribution = recognized revenue less acquisition, credit loss, funding, servicing and incentives. Principal is not revenue. Costs are mutually exclusive totals in the same currency and cohort. Credit loss is a single loss measure, never ECL plus realized loss. Maturity is supplied metadata, not independently established by this tool. Immature contribution → null. No APR, default probability, regulatory capital, lifetime value or causal uplift is estimated.

## Input and diagnostic behavior

The bundled [input contract](../skills/growth-funnel-diagnosis/references/input-contract.md) defines the exact accepted JSON fields and a standalone example. Dates must be valid/ordered; maturity must be an explicit boolean. Missing/extra fields and duplicate cohort/window identities are rejected. The CLI also rejects duplicate JSON object keys. Currency syntax is checked; no currency registry or exchange-rate conversion is performed. Existing valid demo input and original JSON output fields are retained; previously tolerated malformed input may now fail validation.

Reports show both people not progressing and conversion for every transition. Acquisition-to-disbursement investigation candidates are ranked separately by count not progressing and lowest observed conversion; ties remain visible. A low approval rate can be a correct policy outcome. Repayment and repeat are reported but excluded from onboarding candidate rankings. Their complements do not establish default or abandonment. No causal ranking, predicted uplift or automatic winner is calculated. Cohorts are never combined implicitly across dates, currencies or populations.
