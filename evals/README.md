# Agent acceptance suite

Run date: 2026-11-03. Baseline: 72c1ef538a88610e87a49ca5833a61ea39474280.

Each skill is copied into an isolated task directory with its bundled resources and only the synthetic inputs needed. A fresh agent receives the task and file paths, without the rubric, prior conclusions or expected outputs. Agents must complete the task and save their actual output; do not substitute a checklist or self-grade for execution. The reviewer checks the artifacts against the criteria below. These runs exercise explicitly loaded skills, not automatic host discovery or all-model compatibility.

## Gates declared before execution

- All skills: complete the requested deliverable with source-bound facts; mark unsupported assumptions; preserve the user's scope; no fabricated results, legal conclusions, customer contact or live-system mutation.
- Architect: separate request/provider/ledger completion; deduplication and ambiguous-timeout recovery prevent duplicate funding; dependency-ordered backlog has owner roles, acceptance and recovery; correlations are hypotheses and sprint timing is conditional.
- Metric tree: reconcile both first-loan fixtures; define denominators, window, currency and loss basis; no double subtraction of ECL/realized loss; no loan-to-borrower denominator substitution; immature/missing-cost economics cannot be claimed as mature; unrepaid is not default.
- Funnel: execute the bundled calculator and preserve arithmetic; distinguish count versus rate priorities and policy/delayed outcomes; propose disconfirming checks; reject non-nested independent event populations without fabricating corrected counts.
- Experiment: fill the card, including ITT/assignment, contamination, power/traffic unknowns, numeric guardrails, stopping and delayed-risk gates; calculate pilot proportions descriptively but do not endorse post-treatment denominators, unplanned daily peeking or scale from immature zero loss.

A skill passes only when every critical gate is satisfied by an observed output and no material arithmetic or decision error remains. Record failures, narrow fixes and fresh reruns. Calculation tests are supporting evidence, not substitutes for agent behavior.
