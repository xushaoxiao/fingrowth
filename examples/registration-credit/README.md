# Registration-to-credit: first business workflow

用户选择的首个场景：**注册 → 填资 → KYC → 银行资料 → 授信**。

- [五阶段定义、转化公式与诊断边界](../../skills/growth-funnel-diagnosis/references/registration-credit.md)
- [匿名聚合采集模板](../../skills/growth-funnel-diagnosis/assets/registration-credit-intake.json)

当前没有人数、时间窗口或生产事件定义，因此所有转化率和瓶颈均为未知。先验证五阶段同一cohort、去重、顺序和随访口径；再按未继续人数与转化率分别定位调查优先级；最后才设计实验。

授信暂按审批通过理解；银行资料暂按后端校验并保存理解，均须业务确认。示例不包含真实数据，也不将已发布九阶段合成计算器冒充为这条业务漏斗的计算工具。

给 Agent 的起始任务：读取 growth-funnel-diagnosis/SKILL.md、这条 journey contract 和 intake，列出当前可确认的口径、缺失输入、可计算公式和禁止下结论的项目。收到有授权的聚合数据前，不输出转化数值、优先级或因果结论。
